# GitHub Repository Explorer

A simple and responsive web application that allows users to search for GitHub repositories using keywords and explore relevant repository information through the GitHub REST API.

## Live Demo

[View GitHub Repository Explorer](https://dhruvkmr08-alt.github.io/github-repository-explorer1/)

## Features

- **Repository Search:** Search for GitHub repositories using keywords.
- **API Integration:** Fetch repository information using the GitHub REST API.
- **Repository Information:** Display repository names and relevant details.
- **More Details:** Explore additional information about repositories using the available details option.
- **Responsive Interface:** Provides a user-friendly interface across supported screen sizes.

## Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Styles the interface and supports responsive layouts.
- **JavaScript** – Handles user interactions, search functionality and API responses.
- **GitHub REST API** – Provides repository search results and related information.

## How It Works

1. The user enters a keyword in the search field.
2. The application sends a request to the GitHub REST API.
3. The API returns repository data matching the search query.
4. JavaScript processes the response and displays the relevant results.
5. The user can select the available "More Details" option to explore further repository information.
